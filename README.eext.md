# 原理图AI检测

嘉立创 EDA 专业版原理图分析扩展。它通过 EDA API 采集器件、引脚和网络关系，
将结构化原理图数据提供给用户配置的 OpenAI 兼容模型。

## 功能

- 原理图结构化采集和多页支持
- AI 对话分析与 reasoning 显示
- 点击器件位号或网络名定位
- 配置与聊天历史持久化
- 可选 MCP 工具调用和只读数据桥接

## 使用

1. 打开原理图。
2. 选择 `AI检测 -> 原理图AI检测...`。
3. 在界面中配置 API URL、API Key 和模型。
4. 输入问题并基于当前原理图进行分析。

## 隐私提示

启用 AI 请求后，所选原理图字段和用户附件会发送到用户配置的模型服务。
API Key 保存在 EDA 扩展存储中。
